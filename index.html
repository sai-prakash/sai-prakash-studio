For the curious

Method प्रत्याहारpratyāhāra, a set named in two letters

The oldest design system I know.

Around the 4th century BCE, Pāṇini described all of Sanskrit in nearly 4,000 short rules. Before the rules come 14 lines of sounds, each ending in a marker.

Rule 1.1.71 says a sound plus a later marker names every sound in between. Two letters can stand for a whole set. In a design system we'd call that a token alias.

aCअच्

names the vowels, 9 sounds.

--aC: a i u ṛ ḷ e o ai au;

  1. Name a set once, then refer to it everywhere.
  2. State the rule in one line. Keep the reasoning one tap away.
  3. Write it so people and agents read the same thing.
  4. Test that the agent followed it, and publish the score.

In 1967, Peter Ingerman suggested calling Backus–Naur form “Pāṇini–Backus form”, because Pāṇini's rules work in a similar way.
